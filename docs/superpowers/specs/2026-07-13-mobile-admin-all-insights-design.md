# 小程序管理员全量查看小凡看见设计

## 目标

小程序管理员在“他人的”标签中查看当前租户所有用户、所有期次的已完成小凡看见，不依赖 `InsightRequest` 获批记录；管理员本人的记录允许与“我的”标签重复。普通用户继续按现有申请授权逻辑查看。

## 方案

- 后端新增小程序用户 JWT 鉴权的管理员聚合接口，角色限定为项目现有管理员角色集合。
- 查询固定限定当前租户、`type=insight`、`status=completed`，支持分页并填充期次、课节、创建者和被看见人。
- 小程序管理员加载“他人的”时循环读取全部分页；普通用户仍先读取已批准申请，再逐人读取获准内容。
- 管理员结果直接使用每条记录的 `targetUserId` 展示昵称和头像，不做用户去重，也不排除管理员本人。

## 权限与错误处理

- 非管理员调用聚合接口返回 403。
- 租户条件同时由 `userTenantContext` 和查询中的 `tenantId` 约束，避免跨租户读取。
- 任一分页失败时整次管理员列表加载失败，沿用页面现有日志处理，不混入部分数据。

## 测试

- 后端：管理员可获取全量记录；查询包含租户、类型和完成状态；普通用户返回 403；分页字段正确。
- 小程序：管理员不调用申请列表，能够合并多页全量记录；普通用户仍调用原授权链路。
